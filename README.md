# ドットの作業部屋

ドット絵の作業部屋。部屋の中の物をクリックすると、ポモドーロ・ToDo・環境音・メモなどの作業ツールが開きます。
スマホでもPCでも、ホーム画面に追加するとアプリのように使えます。一度ネットにつながった状態で開けば、その後は電波のないところでも動きます（フォントも最初に開いたときに保存されます）。

## ファイル構成

| パス | 中身 |
|---|---|
| `index.html` | 部屋そのもの（描画・機能・保存をすべて含む） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色 |
| `sw.js` | オフライン用のキャッシュ（更新したら `VERSION` を上げる） |
| `icons/` | アイコン（192・512・iPhone用180） |
| `.nojekyll` | GitHub Pages でそのまま配信するための空ファイル |

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`pixel-room`、Public）。
2. このフォルダの中身をすべてアップロードする（「Add file → Upload files」にフォルダの中身をドラッグ）。
3. リポジトリの「Settings → Pages」で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして保存。
4. 数分後に `https://ユーザー名.github.io/pixel-room/` で開けるようになる。

## スマホでアプリのように使う

- iPhone：Safari で開く → 共有ボタン →「ホーム画面に追加」
- Android：Chrome で開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）

## データについて

- データは、使っているブラウザ（端末）の中に保存されます。
- 別の端末へ移すときは、部屋のPCにある「データの保存」で書き出し、移した先で読み込みます。
- アップロードした曲・録音の再生と、端末間の自動同期は、Claude のウィジェット版だけの機能です。

## 更新のしかた

1. `index.html` などを差し替えてアップロードする。
2. `sw.js` の `VERSION`（例：`room-v1` → `room-v2`）を上げる。
3. スマホではアプリを一度閉じて開き直すと、新しい版になります。
